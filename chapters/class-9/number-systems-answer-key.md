## Full solution methods (explain mistakes using these steps)

**Q1.** $0.375=\frac{375}{1000}=\frac38$ (divide by $125$).

**Q2.** Let $x=0.\overline{3}$; $10x=3.\overline{3}$; subtract: $9x=3\Rightarrow x=\boxed{\frac13}$.

**Q3.** Numerator $2^6\times2^3=2^9$; $\frac{2^9}{2^4}=2^{9-4}=2^5=\boxed{32}$.

**Q4.** $\sqrt{2}$ cannot be written as $\frac pq$; its decimal $1.41421356\ldots$ never terminates or repeats $\rightarrow \boxed{\text{irrational}}$.

**Q5.** Average: $\frac12(\frac23+\frac34)=\frac12\times\frac{17}{12}=\boxed{\frac{17}{24}}$.

**Q6.** $0.6=\frac6{10}=\boxed{\frac35}$.

**Q7.** Let $x=0.\overline{7}$; $10x=7.\overline{7}$; subtract: $9x=7\Rightarrow x=\boxed{\frac79}$.

**Q8.** $5^2\times5^3=5^{2+3}=5^5=\boxed{3125}$.

**Q9.** $(3^2)^3=3^{2\times3}=3^6=\boxed{729}$.

**Q10.** Average: $\frac12(\frac12+\frac23)=\frac12\times\frac76=\boxed{\frac7{12}}$.

**Q11.** Denominator $8=2^3$, only prime factor 2 $\rightarrow$ $\boxed{\text{terminating }(0.875)}$.

**Q12.** $\sqrt{2}\approx1.414$ lies between 1 and 2, and 2 is not a perfect square $\rightarrow \boxed{\text{irrational}}$.

**Q13.** $\frac38=\frac{375}{1000}=\boxed{0.375}$.

**Q14.** $\frac{7^5}{7^2}=7^{5-2}=7^3=\boxed{343}$.

**Q15.** $12\times12=144\Rightarrow\boxed{12}$.

**Q16.** $3^2=9<10<16=4^2\Rightarrow\boxed{3\text{ and }4}$.

**Q17.** The zeros between the 1s keep increasing ($1,00,000,\ldots$), so there is no fixed repeating block $\rightarrow\boxed{\text{irrational}}$.

> **Common mistakes to watch for:** (i) writing $0.\overline{3}=\frac{3}{10}$ instead of $\frac13$; (ii) multiplying indices instead of adding when multiplying powers; (iii) claiming $\sqrt{2}=1.414$ exactly (it's approximate); (iv) thinking every non-terminating decimal is irrational (recurring decimals like $0.\overline{3}$ are rational). Revisit Number Systems if several of these appear.
