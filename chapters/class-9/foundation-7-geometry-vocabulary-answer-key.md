## Full solution methods (explain mistakes using these steps)

**Q1.** Angles on a straight line add to $180$: $x=180-125=\boxed{55^\circ}$.

**Q2.** Angles in a triangle add to $180$: $180-48-67=\boxed{65^\circ}$.

**Q3.** All three sides equal ($7,7,7$) $\rightarrow$ $\boxed{\text{equilateral}}$.

**Q4.** Exactly two sides equal ($6,6,10$) $\rightarrow$ $\boxed{\text{isosceles}}$.

**Q5.** $(-4,-5)$: $x<0$, $y<0$ $\rightarrow$ $\boxed{\text{Quadrant III}}$.

**Q6.** $(3,-2)$: $x>0$, $y<0$ $\rightarrow$ $\boxed{\text{Quadrant IV}}$.

**Q7.** Midpoint $=\left(\frac{2+8}{2},\frac{4+10}{2}\right)=\boxed{(5,7)}$.

**Q8.** Midpoint $=\left(\frac{-2+4}{2},\frac{4-2}{2}\right)=\boxed{(1,1)}$.

**Q9.** One angle is $90^\circ$ $\rightarrow$ $\boxed{\text{right-angled triangle}}$.

**Q10.** Angles in a quadrilateral add to $360$: $360-(85+95+110)=360-290=\boxed{70^\circ}$.

**Q11.** $x=180-70=\boxed{110^\circ}$.

**Q12.** $180-50-70=\boxed{60^\circ}$.

**Q13.** All three sides different ($5,12,13$) $\rightarrow$ $\boxed{\text{scalene}}$.

**Q14.** $(-3,4)$: $x<0$, $y>0$ $\rightarrow$ $\boxed{\text{Quadrant II}}$.

**Q15.** Midpoint $=\left(\frac{0+6}{2},\frac{0+8}{2}\right)=\boxed{(3,4)}$.

> **Common mistakes to watch for:** (i) using 180 instead of 360 for a quadrilateral; (ii) mixing up quadrant order (II is top-left, IV is bottom-right); (iii) calling an isosceles triangle equilateral when only two sides match; (iv) averaging coordinates incorrectly (sign errors with negatives). Revisit Foundation 7 if several of these appear.
