> **How to use:** Ask your child to show their working for each question. Mark correct with a tick. For any wrong answer, go back to the first step where the method slipped and explain it using the method below — do not just give the final answer.

## Full solution methods (explain mistakes using these steps)

**Q1.** Same base, add indices: $2^3\times2^2=2^{3+2}=2^5=\boxed{32}$.

**Q2.** Power of a power, multiply indices: $(3^2)^3=3^{2\times3}=3^6=\boxed{729}$.

**Q3.** Number squared giving 144: $12\times12=144$, so $\boxed{12}$.

**Q4.** Same base, subtract indices: $\frac{5^7}{5^3}=5^{7-3}=5^4=\boxed{625}$.

**Q5.** Test $5^3=125$. Yes, $125=5^3$, so $\sqrt[3]{125}=\boxed{5}$.

**Q6.** Area $=\text{side}^2=12^2=\boxed{144\text{ cm}^2}$.

**Q7.** Volume $=\text{edge}^3=5^3=\boxed{125\text{ cm}^3}$.

**Q8.** Doubles each hour for 8 hours: $2^8=\boxed{256}$.

**Q9.** Numerator $2^6\times2^3=2^9$; divide by $2^4$: $2^{9-4}=2^5=\boxed{32}$.

**Q10.** $15\times15=225$, so $\boxed{15}$.

**Q11.** $8\times8\times8=512$, so $\boxed{8}$.

**Q12.** $3^3=27$, $2^4=16$, $5^2=25$; $27+16-25=\boxed{18}$.

**Q13.** $4^3\times4^2=4^{3+2}=4^5=\boxed{1024}$.

**Q14.** $\frac{6^5}{6^2}=6^{5-2}=6^3=\boxed{216}$.

**Q15.** $10\times10\times10=1000$, so $\sqrt[3]{1000}=\boxed{10}$.

> **Common mistakes to watch for:** (i) multiplying indices instead of adding when multiplying powers; (ii) subtracting in the wrong order when dividing powers; (iii) writing $\sqrt{144}=12$ but then using it as $144$ in area; (iv) confusing square root with dividing by 2. Revisit Foundation 4 if several of these appear.
