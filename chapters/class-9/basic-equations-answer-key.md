## Full solution methods (explain mistakes using these steps)

**Q1.** $3x+7=22 \Rightarrow 3x=15 \Rightarrow x=\boxed{5}$.

**Q2.** $\frac{x}{4}=9 \Rightarrow x=9\times4=\boxed{36}$.

**Q3.** $2x-5=11 \Rightarrow 2x=16 \Rightarrow x=\boxed{8}$.

**Q4.** $4(x-3)=20 \Rightarrow x-3=5 \Rightarrow x=\boxed{8}$.

**Q5.** $5x+3=3x+11 \Rightarrow 2x+3=11 \Rightarrow 2x=8 \Rightarrow x=\boxed{4}$.

**Q6.** $2x+7=25 \Rightarrow 2x=18 \Rightarrow x=\boxed{9}$.

**Q7.** $6p=72 \Rightarrow p=\boxed{₹12}$.

**Q8.** $x+(x+3)=27 \Rightarrow 2x+3=27 \Rightarrow 2x=24 \Rightarrow x=\boxed{12}$.

**Q9.** $2(w+w+3)=30 \Rightarrow 4w+6=30 \Rightarrow 4w=24 \Rightarrow w=\boxed{6\text{ m}}$.

**Q10.** $x+(x+20)+90=180 \Rightarrow 2x+110=180 \Rightarrow 2x=70 \Rightarrow x=\boxed{35^\circ}$.

**Q11.** $m+150=850 \Rightarrow m=\boxed{₹700}$.

**Q12.** $\frac{s}{5}=8 \Rightarrow s=\boxed{40}$.

**Q13.** $7x-4=31 \Rightarrow 7x=35 \Rightarrow x=\boxed{5}$.

**Q14.** $\frac{x+2}{3}=5 \Rightarrow x+2=15 \Rightarrow x=\boxed{13}$.

**Q15.** $3(x+4)=27 \Rightarrow x+4=9 \Rightarrow x=\boxed{5}$.

> **Common mistakes to watch for:** (i) undoing operations in the wrong order (divide before subtracting); (ii) forgetting to do the same operation to both sides; (iii) writing $4(x-3)=20$ then $4x-3=20$ instead of dividing by 4 first; (iv) sign errors when collecting variables on both sides. Revisit Basic Equations if several of these appear.
