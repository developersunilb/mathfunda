# Chapter 4: Exploring Algebraic Identities

## 4.1 Visualising identities

Algebraic identities are equations true for all values of variables.

## 4.2 Common identities

- $(a+b)^2 = a^2 + 2ab + b^2$
- $(a-b)^2 = a^2 - 2ab + b^2$
- $a^2 - b^2 = (a-b)(a+b)$

## 4.3 Factorisation using identities

Use identities to factorise expressions.

## 4.4 New identities

Derive identities by expansion.

## Formula reference

| Identity | Meaning |
|---|---|
| (a+b)² = a²+2ab+b² | Square of sum |
| a²-b² = (a-b)(a+b) | Difference of squares |
