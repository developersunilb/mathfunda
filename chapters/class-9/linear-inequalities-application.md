# Linear Inequalities: Application Questions

Application questions for **Linear Inequalities**. Attempt each on paper before checking the answer key.

## 1. Solve

Solve $x+5>12$.

## 2. Solve (sign flip)

Solve $-2x<10$.

## 3. Solve

Solve $3x-4<8$.

## 4. Solve

Solve $5-2x\ge1$.

## 5. Graph

Show $x>3$ on a number line.

## 6. Graph

Show $x\le-2$ on a number line.

## 7. Word problem

A student needs at least 40 marks to pass. She already has 28. How many more $m$ does she need?

## 8. Word problem

A lift can carry at most 600 kg. Each box weighs 25 kg. Find the maximum number of boxes $b$ the lift can carry.

## 9. Solve

## 10. Solve
