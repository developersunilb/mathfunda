# Foundation 1: Application Questions

Application questions for **Numbers and Signs**. Attempt each one on paper before checking the answer key.

## 1. Temperature drop

At 6 a.m. the temperature was $-4^\circ\text{C}$. By noon it had risen by $9^\circ\text{C}$, and by evening it fell by $7^\circ\text{C}$. What was the temperature in the evening?

## 2. Bank account

Meena's bank account shows a balance of $-\text{₹}500$ (overdrawn). She deposits $\text{₹}800$, then withdraws $\text{₹}300$. What is her final balance?

## 3. Buying and selling

A shopkeeper buys an item for $\text{₹}120$ and sells it at a loss, so the selling price is $\text{₹}95$. Express the result as a signed change from the cost price, and find the loss.

## 4. Hill and valley

A point on a hill is $84\text{ m}$ above sea level, and a point in a valley is $37\text{ m}$ below sea level. Find the difference in height between the two points.

## 5. BODMAS in a receipt

A receipt calculates $24\div3\times2+4$ for a discount. A student worked it out as $24\div(3\times2+4) = 24\div10 = 2.4$. Is the student correct? If not, give the correct value using BODMAS.

## 6. Place value cheque

A cheque is written for $5,06,742$. State the place value of the digit $6$ and the face value of the digit $5$.

## 7. Division algorithm

A number leaves remainder $3$ when divided by $7$. Write it in the form $\text{dividend}=\text{divisor}\times\text{quotient}+\text{remainder}$, using quotient $5$.

## 8. Sign check

Without calculating the full value, decide the sign of each result:
$(a)\ (-5)\times(-3)\times(-2)$
$(b)\ (-45)\div(+9)\times(-2)$
