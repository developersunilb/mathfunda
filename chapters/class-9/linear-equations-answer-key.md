## Full solution methods (explain mistakes using these steps)

**Q1.** Move all terms to one side: $2x+3y-12=0$. So $a=2,\;b=3,\;c=-12$.

**Q2.** Substitute $x=1,\;y=5$: $1+2(5)=1+10=11$. Both sides match. $\boxed{\text{Yes}}$.

**Q3.** Substitute $x=4,\;y=2$ into $x-y=2$: $4-2=2$. Both sides match. $\boxed{\text{Yes}}$.

**Q4.** Form $y=mx+d$: $m=2,\;d=1$. $\boxed{\text{Slope }2,\text{ y-intercept }1}$.

**Q5.** Cost $C=30+15d$. For $d=8$: $C=30+15(8)=30+120=\boxed{₹150}$. Valid domain $d\ge0$ (flag-fall applies even at zero distance).

**Q6.** $m+d=46,\;m-d=20$. Add: $2m=66\Rightarrow m=33$. Then $d=46-33=13$. $\boxed{\text{Mother }33,\text{ daughter }13}$. Check: $33+13=46,\;33-13=20$ ✓.

**Q7.** Let tens digit be $x$, units digit be $y$: $x+y=11$ and $(10x+y)-(10y+x)=27\Rightarrow 9x-9y=27\Rightarrow x-y=3$. Solving: $2x=14\Rightarrow x=7,\;y=4$. $\boxed{74}$. Check: $7+4=11$; reverse 47; $74-47=27$ ✓.

**Q8.** From $x-y=2$: $x=y+2$. Substitute into $2x+y=7$: $2(y+2)+y=7\Rightarrow 3y+4=7\Rightarrow y=1,\;x=3$. $\boxed{(3,1)}$. Check: $2(3)+1=7,\;3-1=2$ ✓.

**Q9.** Add the equations: $(3x+4y)+(6x-4y)=10+2\Rightarrow 9x=12\Rightarrow x=\frac43$. Substitute: $3(\frac43)+4y=10\Rightarrow 4+4y=10\Rightarrow y=\frac32$. $\boxed{(\frac43,\frac32)}$. Check: $3(\frac43)+4(\frac32)=4+6=10$ ✓; $6(\frac43)-4(\frac32)=8-6=2$ ✓.

**Q10.** The second equation $2x+4y=12$ is exactly $2$ times the first $x+2y=6$. Both describe the same line. $\boxed{\text{Infinitely many solutions (coincident lines)}}$.

**Q11.** Both equations have the same left side $x+y$ but different right sides ($4$ and $7$). The lines are parallel and distinct. $\boxed{\text{No solution}}$.

**Q12.** Line 1 ($3x+2y=12$): passes through $(0,6)$ and $(4,0)$. Line 2 ($x-y=1$): passes through $(1,0)$ and $(0,-1)$. Algebraically: from $x-y=1$, $x=y+1$. Substitute: $3(y+1)+2y=12\Rightarrow 5y+3=12\Rightarrow y=\frac95,\;x=\frac{14}{5}$. $\boxed{(\frac{14}{5},\frac95)}$. Check: $3(\frac{14}{5})+2(\frac95)=\frac{42+18}{5}=\frac{60}{5}=12$ ✓; $\frac{14}{5}-\frac95=\frac55=1$ ✓.

**Q13.** Infinite solutions requires $\frac{k}{3}=\frac{2}{6}=\frac{5}{15}$. Since $\frac{2}{6}=\frac{5}{15}=\frac13$, we need $\frac{k}{3}=\frac13\Rightarrow k=1$. $\boxed{k=1}$. Check: $x+2y=5$ and $3x+6y=15$ → second is $3\times$ first → coincident ✓.

**Q14.** No solution requires $\frac{k}{2}=\frac{3}{6}\ne\frac{5}{12}$. Since $\frac{3}{6}=\frac12$, we need $\frac{k}{2}=\frac12\Rightarrow k=1$. Then $\frac12\ne\frac{5}{12}$ holds. $\boxed{k=1}$. Check: $x+3y=5$ and $2x+6y=12\Rightarrow x+3y=6$. So $x+3y=5$ and $x+3y=6$ → contradiction ✓.

**Q15.** $3p+2e=14,\;2p+3e=16$. Multiply first by 3: $9p+6e=42$. Multiply second by 2: $4p+6e=32$. Subtract: $5p=10\Rightarrow p=2$. Then $3(2)+2e=14\Rightarrow e=4$. $\boxed{\text{Pencil }₹2,\text{ eraser }₹4}$. Check: $3(2)+2(4)=14$ ✓; $2(2)+3(4)=16$ ✓.

> **Common mistakes to watch for:** (i) sign error when converting to standard form; (ii) forgetting the domain qualification on “infinitely many”; (iii) dividing by zero in the ratio test when a coefficient is zero; (iv) sign error in elimination (add to cancel opposite signs, subtract to cancel same signs); (v) digit-reversal setup must use $10x+y$, not $x+y$; (vi) the chapter's worked taxi example (₹50 flag-fall) has a meaningful y-intercept at $d=0$ because the domain starts at $d\ge0$. (Practice Question 5 uses ₹30 flag-fall plus ₹15/km.)
