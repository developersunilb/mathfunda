## Full solution methods (explain mistakes using these steps)

**Q1.** Substitute each $x$ into $y=3x-2$: $y=-2,1,4,7,10$.

**Q2.** Form $y=mx+c$; $m=1$, $c=2$. $\boxed{\text{Gradient }1,\text{ y-intercept }2}$.

**Q3.** $2x-5=11 \Rightarrow 2x=16 \Rightarrow x=\boxed{8}$.

**Q4.** $\frac{x}{4}=9 \Rightarrow x=9\times4=\boxed{36}$.

**Q5.** Gradient $m=\frac{8-4}{2-0}=2$; y-intercept from $(0,4)$ is $4$. $\boxed{y=2x+4}$.

**Q6.** Substitute $x=3$: $y=3(3)+1=10$, matches. $\boxed{\text{Yes}}$.

**Q7.** $C=50+12d$; for $d=15$: $C=50+180=\boxed{₹230}$.

**Q8.** Gradient $m=\frac{11-3}{4-0}=\frac84=2$; y-intercept $c=3$. $\boxed{y=2x+3}$.

**Q9.** $5x+3=3x+11 \Rightarrow 2x+3=11 \Rightarrow 2x=8 \Rightarrow x=\boxed{4}$.

**Q10.** Set $2x+1=x+4 \Rightarrow x=3$; $y=2(3)+1=7$. $\boxed{(3,7)}$.

**Q11.** Substitute into $y=2x+3$: $x=-1\Rightarrow y=1$; $x=0\Rightarrow y=3$; $x=1\Rightarrow y=5$; $x=2\Rightarrow y=7$.

**Q12.** Gradient $m=\frac{11-5}{3-1}=\frac62=3$. Using $(1,5)$: $5=3(1)+c\Rightarrow c=2$. $\boxed{y=3x+2}$.

**Q13.** $4x-7=9 \Rightarrow 4x=16 \Rightarrow x=\boxed{4}$.

**Q14.** $\frac{x-3}{2}=5 \Rightarrow x-3=10 \Rightarrow x=\boxed{13}$.

**Q15.** Substitute $x=-1$: $y=2(-1)+3=-2+3=1$, matches $y=1$. $\boxed{\text{Yes}}$.

> **Common mistakes to watch for:** (i) gradient sign error (rise/run); (ii) using the wrong point for the y-intercept; (iii) forgetting to do the same operation to both sides; (iv) substituting $x$ but forgetting to compute $y$ when checking a solution. Revisit Linear Equations if several of these appear.
